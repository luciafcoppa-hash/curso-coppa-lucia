Dataset original – PaySim

Para este proyecto se utilizó el dataset PaySim, que contiene 6.362.620 transacciones financieras simuladas.

Fuente original: PaySim – Kaggle

El archivo original PS_20174392719_1491204439457_log.csv tiene un tamaño aproximado de 470 MB.

Debido a su tamaño, no se incorpora directamente a GitHub. Puede obtenerse desde el enlace a Kaggle indicado anteriormente.

El análisis exploratorio se encuentra en la carpeta notebooks y la visualización del dashboard en la carpeta dashboard.
